**Exercise 1 (Beginner):**  
Create three variables to store your name, age, and favorite color. Print them in a single sentence.

---

**Exercise 2 (Intermediate):**  
Create two variables for numbers. Print their sum, difference, product, and division result.

---

**Exercise 3 (Challenging):**  
Ask the user for their birth year. Store it in a variable and calculate their current age. Then display a message like:  
_"You are X years old."_
